# VeyraFX Studio AI — Updated HTML ZIP

This recreated starter version replaces the previous **Simulon Studio AI** branding with **VeyraFX Studio AI**.

Included:
- `index.html` — single-file 3D browser studio
- Add cube/sphere; GLB/GLTF import
- Image/video background
- Transform and lighting sliders
- PNG screenshot export and WebM recording

## GitHub Pages update
1. Extract the ZIP.
2. In `veyrafx-studio-ai`, use **Add file → Upload files** to upload the included `index.html`.
3. Commit to `main`, then refresh your Pages website.

Three.js loads from a CDN, so internet is required. This is a recreated starter package, not a byte-for-byte recovery of the earlier file.
